WHY ONE STEP IS CAUTIOUS

Defaulted and arranged accounts are never treated like ordinary overpayments

Use the Review Inbox action to confirm the fictional arrangement. OneStep protects the agreed payment and still does not assign discretionary overpayments to that account.

Presentation

Theme

The demo uses the same Light, Night and Follow System contract as desktop OneStep.

Demo state

Changes are stored only in this browser tab using session storage. Closing the tab disposes of them. Reset restores the canonical fictional baseline.

Privacy boundary

No account, analytics, advertising SDK, cloud financial storage, remote logging or real document upload is used. The Windows desktop app remains the authoritative private local-first product.

Desktop-only features

Encrypted backup/restore, the private document vault, live filesystem imports, updates and local model integration require the Windows app. The browser demo labels these boundaries rather than pretending they are web services.
